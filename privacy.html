Privacy policy

Effective 2 October 2026

financeguru is a YouTube channel run by an individual based in Hungary. To publish its videos, the channel uses a private publishing tool. This policy explains what that tool and this website do with data.

Who uses the publishing tool

Only the owner of the financeguru channel. The tool is not offered to the public, and it never accesses anyone else's Google account.

Google and YouTube data the tool accesses

The tool uses YouTube API Services, with the channel owner's permission, to:

  • upload videos, thumbnails and their descriptions to the financeguru channel, and set them to public or scheduled;
  • read public information about videos in the channel's topic area, to see what viewers are interested in;
  • read view counts and analytics for the channel's own videos, to measure how they perform.

How the data is used and stored

  • The data is used only to publish the channel's videos and plan future ones. It is never sold, never used for advertising, and never combined with data about other people.
  • The sign-in token and the performance numbers are stored on a private server controlled by the channel owner, and deleted when the tool is disconnected.
  • Titles and performance numbers of the channel's own videos may be processed by an AI service (Anthropic's Claude) to suggest topics for future videos. No other Google user data is shared with anyone.

Revoking access

Access can be revoked at any time on the Google security settings page. Stored data is then deleted within 30 days.

YouTube and Google terms

By using a tool built on YouTube API Services, the channel owner agrees to the YouTube Terms of Service. Google's handling of data is described in the Google Privacy Policy.

Visitors to this website

This website does not use cookies, analytics or tracking. It is hosted on GitHub Pages, which may process technical data such as your IP address to deliver the page, as described in GitHub's privacy statement. Fonts are loaded from Google Fonts.
